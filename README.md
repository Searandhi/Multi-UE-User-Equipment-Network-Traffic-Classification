🚀 Multi-UE Network Traffic Classification using Stacking Ensemble

📌 Problem Statement

Modern networks support multiple User Equipment (UE) such as smartphones, laptops, and IoT devices. Each device generates different types of network traffic depending on the application being used.

Applications like Video Streaming, Audio Calls, Video Calls, Gaming, Browsing, File Uploads, and Messaging behave differently under varying network conditions such as bandwidth, latency, and channel state.

Identifying the type of traffic helps networks provide optimized Quality of Service (QoS) and efficient resource allocation.

Traditional traffic classification methods rely on Deep Packet Inspection (DPI), which can raise privacy concerns and increase computational complexity.

This project develops an AI-based Machine Learning model to analyze network flow patterns and accurately classify application traffic.

📖 Project Overview

This project focuses on classifying network traffic generated by multiple users (UE) using Machine Learning techniques.

The model analyzes network flow features and predicts which application is generating the traffic.

Traffic categories include:

🌐 Browsing

🎥 Video Streaming

💬 Chat / Messaging

📂 File Transfer

📞 VoIP Calls

🔐 VPN Traffic

To improve prediction performance, the system uses a Stacking Ensemble Machine Learning Model that combines multiple algorithms.

🧠 Models Used

Base Models
⚡ XGBoost
🌲 LightGBM

Meta Model
📊 Logistic Regression

The ensemble model achieves 97.53% classification accuracy.
