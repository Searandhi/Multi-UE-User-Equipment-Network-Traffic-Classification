AI Multi-UE Network Traffic Classification
Project Overview

This project focuses on classifying network traffic generated by multiple users (UE – User Equipment such as mobile phones, laptops, and IoT devices) using Machine Learning techniques.

The system analyzes network flow features and identifies the application generating the traffic, such as browsing, streaming, chat, file transfer, and VoIP. This helps improve network resource allocation and Quality of Service (QoS).

A stacking ensemble machine learning model combining XGBoost, LightGBM, and Logistic Regression is used to achieve high classification accuracy.

Problem Statement

Modern networks handle multiple applications simultaneously, generating diverse traffic patterns. Traditional traffic inspection methods rely on deep packet inspection, which may raise privacy concerns.

This project aims to classify traffic using flow-level features without inspecting user content, enabling efficient and privacy-preserving traffic management.

Dataset

The project uses the CIC VPN-NonVPN Dataset, which contains network traffic flows captured from multiple applications.

Dataset Characteristics:

~55,000 network flow samples

14 traffic categories

13 original traffic features

Traffic Classes:

Browsing
Chat
File Transfer
Mail
P2P
Streaming
VoIP
VPN versions of the above applications

Feature Engineering

The dataset originally contains 13 features. Additional engineered features are created from network statistics such as:
packet rate
byte rate
flow duration
packet size relationships
After feature engineering, the dataset contains approximately 33 features used for training.

Model Performance

The final stacking ensemble model achieved:
Accuracy: 97.53%
Balanced Accuracy: 97.24%
This demonstrates strong performance in classifying different types of network traffic.
